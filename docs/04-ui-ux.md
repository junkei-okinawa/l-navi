## 1. 概要

## 2. ユーザージャーニー

### 2.1 主要フロー

```
┌─────────────────────────────────────────────────────────────────┐
│                     ユーザージャーニー                          │
└─────────────────────────────────────────────────────────────────┘

[1] ホーム
    │
    ├─ API キー未設定 → [2] API キー設定
    │                      │
    │                      └─ 設定完了 → [3] 新規作成
    │                                     │
    └─ API キー設定済み →─────────────────┤
                                          │
                                          ▼
                                    [4] ヒアリングチャット
                                          │
                                          ├─ AI と対話
                                          │  • 業種確認
                                          │  • ターゲット層確認
                                          │  • 目的確認
                                          │  • 機能選択
                                          │
                                          └─ 要件確定 → [5] チャットシミュレーター
                                                                     │
                                                                     ├─ リッチメニュー編集
                                                                     │  • JSON エディター
                                                                     │  • 視覚的プレビュー
                                                                     │
                                                                     ├─ チャットシミュレーション
                                                                     │  • メッセージ送受信
                                                                     │  • リッチメニュー表示
                                                                     │
                                                                     └─ 本番化判断 → [6] LINE にデプロイ
```

## 4. ヒアリングフロー詳細

### 4.1 対話型ヒアリングのステップ

```
ステップ 1: 業種の確認
─────────────────────────────────────
ユーザー：「カフェの公式アカウントを作りたい」
AI: 「素晴らしいです！カフェの公式アカウントですね。」
    
ステップ 2: ターゲット層の確認
─────────────────────────────────────
AI: 「ターゲット層をお伺いできますか？」
    （例：20-30 代女性、ファミリー層、ビジネスパーソン）
ユーザー：「20-30 代女性です」

ステップ 3: 目的の確認
─────────────────────────────────────
AI: 「主な用途はどれですか？」
    • プロモーション（キャンペーン、新商品案内）
    • カスタマーサポート（FAQ、問い合わせ対応）
    • 予約（テーブル予約、テイクアウト予約）
    • 両方以上
ユーザー：「プロモーションと予約の両方です」

ステップ 4: 機能選択
─────────────────────────────────────
AI: 「どの機能が必要ですか？複数選択可能です。」
    • リッチメニュー
    • ウェルカムメッセージ
    • 自動応答
    • ブロードキャスト
    • 顧客情報管理
ユーザー：「リッチメニューとウェルカムメッセージをお願いします」

ステップ 5: トーン＆マナーの確認
─────────────────────────────────────
AI: 「アカウントのトーン＆マナー是怎样的にしますか？」
    • 親しみやすい
    • 丁寧でフォーマル
    • カジュアル
    • その他
ユーザー：「親しみやすい感じで」

ステップ 6: 要件確定
─────────────────────────────────────
AI: 「要件を確定します。以下で正しいですか？」
    • 業種：カフェ
    • ターゲット：20-30 代女性
    • 目的：プロモーション、予約
    • 機能：リッチメニュー、ウェルカムメッセージ
    • トーン：親しみやすい
ユーザー：「はい、これでお願いします」

→ チャットシミュレーターへ遷移
```
